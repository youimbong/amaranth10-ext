# amaranth10-notifier

> 더존비즈온과 무관한 비공식 프로젝트이며, 아마란스10은 해당 회사의 상표입니다. 공개되지 않은 API를 사용하므로 예고 없이 동작하지 않을 수 있습니다.

사용자가 설정한 더존 아마란스10 사이트의 통합알림을 Chrome 알림으로 보여 주고, 설정하면 Teams로도 전달하는 Chrome 확장 프로그램(Manifest V3).

## 설치 (압축해제된 확장 프로그램 로드)

1. Chrome에서 `chrome://extensions`를 연다.
2. 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 저장소 폴더(`manifest.json`이 있는 폴더)를 고른다.

## 사용

1. 최초 설치 또는 업데이트 시 접속 주소가 없으면 설정 화면이 자동으로 열린다. **아마란스10 접속 주소**를 입력하고 저장한다. 설정하지 않고 닫았더라도 확장 아이콘을 누르면 설정 화면이 다시 열린다. 해당 사이트 접근 권한을 허용한 뒤 그 사이트에 로그인하고 페이지를 새로고침한다. 확장이 사용자·회사·부서 정보를 수집한다.
2. 이후에는 탭을 닫아도 서비스 워커가 주기적으로(기본 1분) 새 알림을 확인한다.
   - 새 알림이 오면 Chrome 알림(Windows에서는 Windows 알림)을 띄운다. 알림을 누르면 해당 화면을 작은 팝업 창으로 열고 통합알림을 서버에서 읽음 처리한 뒤 배지를 갱신한다. 실패하면 다음에 확장 팝업을 열 때 오류를 안내하며, 알림 클릭을 다시 시도할 수 있다. 0.1.1 업데이트 전에 생성된 알림은 기존처럼 원문만 연다.
   - 툴바 배지에 안 읽은 알림 수를 표시한다.
   - 배지 `!`: 로그인 또는 사이트 접근 권한이 필요하다. 옵션의 상태 안내를 확인한다.
   - 배지 `?`: 사용자 정보가 없다. 설정한 사이트에 로그인하고 페이지를 새로고침한다.
   - 설치하거나 다시 로그인한 직후 첫 확인에서는 기존 알림을 알리지 않고 기준만 잡는다.
3. 확장 아이콘을 누르면 **안읽음**·**전체** 탭으로 알림을 최신순으로 보여 준다(기본 안읽음). 한 번에 20건씩 조회하고 목록 끝까지 스크롤하면 이전 알림을 자동으로 이어서 불러온다. 불러오기에 실패하면 **더 보기**로 다시 시도한다. 안 읽은 알림은 굵게, 빨간 점으로 표시한다.
   - 항목을 누르면 선택 단계 없이 **아마란스10 실제 원문 화면**을 팝업 창으로 연다.
   - 원문 팝업은 하나를 재사용한다. 다른 알림을 누르면 같은 창에서 원문을 새로 로드하고 앞으로 가져온다. 창을 닫았으면 새로 만든다.
   - 원문 팝업 생성에 성공하면 해당 **통합알림을 서버에서 읽음 처리**한다. 목록과 배지는 서버를 다시 조회해 갱신한다.
   - 원문 열기·읽음 처리에 실패하면 안내를 표시한다. 목록 팝업이 닫힌 경우 다음에 열 때 안내한다.
   - 업데이트 후에는 확장을 다시 로드하고 아마란스10 페이지를 한 번 새로고침한다(읽음 API에 필요한 회사·부서 정보 수집).
   - 로그인 필요·사용자 정보 없음·목록 조회 실패 시 **아마란스10 바로가기**와 **새로고침**을 보여 준다. 정상 조회 시에는 숨긴다. 바로가기로 사이트를 열고, 새로고침으로 설정한 접속 주소와 일치하는 열린 탭을 모두 새로고침한다. 탭이 없으면 안내한다.
   - 로그인하지 않았거나 사용자 정보가 없으면 안내한다. 로그인한 상태에서 사용자 정보가 없으면 **새로고침**을 누른다. 정보가 수집되면 알림 목록을 자동으로 다시 조회한다.
   - 탭 위 **임직원 검색창**은 팝업을 열면 바로 입력할 수 있다. 검색어를 지우거나 탭을 누르면 보던 알림 목록으로 돌아간다. 이름·부서·전화번호(네 자리 이상)·내선·이메일로 조직도를 검색한다. `홍길동 개발팀`처럼 단어를 더하면 결과를 좁힌다. 겸직은 한 사람으로 묶고, 연락처를 누르면 복사한다. 최대 50명을 표시한다.
     - 검색할 때마다 서버를 조회하며 결과를 저장하지 않는다.
     - 아마란스10 조직도의 표시 설정을 따른다. 회사가 막았거나 본인이 비공개한 휴대폰, 메일을 쓰지 않는 사람의 이메일은 숨긴다. 설정을 확인하지 못하면 휴대폰을 숨긴다.
   - 오른쪽 위 ⚙: 옵션 페이지.
4. 설정: 팝업의 ⚙ 또는 확장 아이콘 오른쪽 클릭 → **옵션**.
   - **아마란스10 접속 주소**: HTTPS 주소 하나를 설정한다. 로그인 경로·쿼리·해시는 제거하고 기본 주소만 저장한다. 같은 API·쿠키·사용자 정보 구조를 사용하는 아마란스10 환경을 지원하며, 설치 환경별 호환성은 확인이 필요하다.
   - 접속 사이트를 바꾸면 이전 사용자 정보·알림 기준·Chrome 알림·원문 창 연결을 초기화한다. 새 사이트에 로그인하고 페이지를 새로고침하면 첫 조회는 기존 알림을 재전송하지 않고 기준만 잡는다. 이전 사이트 권한은 Teams 전송에도 쓰는 호스트가 아니면 해제한다.
   - Teams 웹후크 URL: Teams 워크플로(Workflows) 웹후크 또는 Incoming Webhook 주소. 비우면 Teams 전달을 끈다. 저장할 때 그 주소에 접근할 권한을 묻는다.
   - 확인 주기(분): 1 이상.
   - **테스트 알림**: Chrome 알림이 뜨는지 확인한다.
   - 상태: 로그인 상태, 마지막 확인 시각, 마지막 오류.

## 구조

```
manifest.json
icons/               아이콘(16/32/48/128)
src/background.js    서비스 워커: 알람 폴링, 쿠키로 로그인 판별, 알림·배지·Teams 전송, 원문 열기·통합알림 읽음 처리
src/content.js       설정한 사이트에서 사용자 정보 수집 → 서비스 워커가 사이트를 검증해 저장
src/options.html/js  옵션 페이지
src/popup.html/js    툴바 팝업: 안읽음·전체 알림 목록, 스크롤 자동 더 보기, 클릭 시 실제 원문 열기, 임직원 검색
src/preview.html/js  미리보기 창: 메일·결재 원문 조회, sandbox iframe 본문
src/lib/site.js      접속 주소 검증·정규화, 사이트 권한 패턴
src/lib/client.js    사이트에 묶인 쿠키 인증·서명 API 호출·팝업 창 열기(서비스 워커·확장 페이지 공용)
src/lib/detail.js    알림 요약, 원문 조회 요청 본문, 미리보기 srcdoc(CSP)
src/lib/amaranth.js  API 서명(wehago-sign)·헤더·요청 본문·알림 클릭 URL 만들기
src/lib/alerts.js    새 알림 선별(첫 실행 시드, alertId·createTime 기준)
src/lib/people.js    임직원 검색어 해석, 조직도 검색 요청, 소속별 행을 사람 단위로 묶기
src/lib/teams.js     Teams Adaptive Card 메시지
test/                단위 테스트 (node --test)
test-e2e/run.mjs     실제 Chromium에 확장을 올린 통합 테스트(API·웹후크 모두 모의)
```

## 테스트

```sh
npm test                      # 단위 테스트
npm i                         # playwright(devDependency)
CHROMIUM_PATH=<Chromium 실행 파일> npm run test:e2e
```

`CHROMIUM_PATH`를 비우면 Playwright 기본 Chromium을 쓴다. e2e 테스트는 확장 사본에 두 모의 사이트와 `http://127.0.0.1/*` 권한을 미리 부여한다(브라우저의 실제 권한 대화상자는 자동화하지 않음). API는 두 호스트 모두 가로채고, 웹후크는 로컬 모의 서버로 보낸다. 권한 거부·철회·기존 권한 해제는 모의 처리해 검증한다. 네이티브 알림 클릭은 자동화할 수 없어, 사본의 서비스 워커에 클릭 처리 함수를 노출해 직접 호출한다. 외부로는 아무것도 보내지 않는다.
